Bookstore Return Procedures

  1. Collect textbooks from the designated drop-off location.
  2. Locate the return confirmation code.
  3. Match the textbook with its return request.
  4. Inspect the textbook for damage.
  5. Update the return status.
  6. Mark the return as completed after verification.
