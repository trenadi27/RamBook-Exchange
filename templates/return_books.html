How to Return Your Books

  1. Complete the textbook return form.
  2. Receive your return confirmation code.
  3. Attach the code to your textbook.
  4. Visit an approved bookstore drop-off location.
  5. Wait for bookstore staff to verify your return.

This is a proposed return service, not an official bookstore system.
